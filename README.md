A chess engine in 4 KB of Python for the [tiny-chess-01 bounty](https://make.fun/bounty/tiny-chess-01): 10x12 mailbox board kept from the mover's side, tapered piece-square evaluation, iterative-deepening PVS with a transposition table, killers, null move, late-move reductions, check extensions and a quiescence search. Fixed node budget per move, no clock, no randomness.

## Run it

```sh
MAKEFUN_ENV_URL=http://localhost:8080 python3 -P -s main.py
```
